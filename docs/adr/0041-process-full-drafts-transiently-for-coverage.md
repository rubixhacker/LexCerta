# Process full drafts transiently for coverage

LexCerta will receive the full submitted draft and identify its citations and quotations itself, so its inventory and findings can be reconciled against the reviewed text. The user accepted this broader processing boundary on September 13, 2026 with transient processing and no retained draft content, including extracted Customer text; this excludes persistent draft content in storage, telemetry, and backups and supersedes ADR 0014's temporary payload-logging exception for that content. The [accepted input formats](../product-scope.md#accepted-launch-input-formats) are pasted text, DOCX, and text-based PDFs; complete host-to-service transfer still requires qualification, and independently retrieved evidence-source data remains subject to the existing source-cache policies.
