# Separate source verification from legal assessment

LexCerta's launch report will distinguish citation-found and quotation-matched findings and explicitly state that current legal status and support for the draft's argument were not assessed. The user accepted this boundary on September 13, 2026 because a source record or textual match can exist for a dissent or an overruled case without supporting the draft's legal proposition. Checking legal treatment, controlling authority, and argumentative support remains outside the launch workflow.
