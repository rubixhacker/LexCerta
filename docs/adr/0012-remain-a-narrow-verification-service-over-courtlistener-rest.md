# Remain a narrow verification service over CourtListener REST

LexCerta will remain a narrow citation-and-quotation evidence-verification service and will call CourtListener's REST API directly. It will not proxy CourtListener's MCP server or compete as a general legal-research interface. Its product boundary is a small stable contract, exact quote verification, explicit provenance and freshness semantics, and durable source caching; general CourtListener research belongs in CourtListener's own MCP service.
