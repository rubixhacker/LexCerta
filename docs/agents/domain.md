# Domain Docs

This is a single-context repository.

## Before exploring

- Read the root `CONTEXT.md` and use its canonical terms.
- Read ADRs under `docs/adr/` that affect the work.
- If either location is absent, proceed without suggesting it be created preemptively.

## Vocabulary

Use the glossary's terms in issue titles, specifications, plans, tests, and implementation. Avoid synonyms explicitly rejected by the glossary.

If required language is missing, reconsider whether it belongs to the project or flag the gap for domain modeling.

## ADR conflicts

Surface conflicts with an accepted ADR explicitly instead of silently overriding the decision.
